## Overview

This assignment covers basic TensorFlow operations, loss functions, neural network training with different optimizers, and TensorBoard visualization using the MNIST dataset.

## Question 1 - Tensor Manipulations and Reshaping

Created a random tensor with shape (4, 6) and used TensorFlow to determine its rank and shape. The tensor was reshaped to (2, 3, 4), transposed to (3, 2, 4), and used to demonstrate broadcasting with a smaller tensor.

## Question 2 - Loss Functions

Implemented Mean Squared Error (MSE) and Categorical Cross-Entropy (CCE) loss functions. The loss values were compared using original and modified predictions, and the results were visualized using Matplotlib.

## Question 3 - Adam vs SGD

Loaded and preprocessed the MNIST handwritten digit dataset. Two neural network models were trained using Adam and SGD optimizers. Training and validation accuracy were compared using plots.

## Question 4 - TensorBoard

Trained a neural network on the MNIST dataset for five epochs and enabled TensorBoard logging. Training and validation accuracy and loss were monitored using TensorBoard.
